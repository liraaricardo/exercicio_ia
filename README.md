Repositório com a resolução de uma lista de 50 exercícios de Python, desenvolvidos em ambiente Jupyter/Colab como parte da disciplina cursada na UMC.

📋 Sobre

Este notebook reúne exercícios que cobrem desde conceitos básicos (variáveis, condicionais, loops) até tópicos intermediários como recursão, algoritmos de ordenação e busca, manipulação de estruturas de dados, criptografia simples e visualização de dados.

🧠 Conteúdos abordados
Fundamentos: entrada/saída de dados, variáveis, operadores aritméticos, f-strings
Estruturas condicionais: if/elif/else, par/ímpar, número primo
Estruturas de repetição: for, while, for...else
Strings: inversão, palíndromo, contagem de caracteres/vogais/palavras, anagramas
Estruturas de dados: listas, dicionários, matrizes (transposta)
Algoritmos: busca binária, bubble sort, insertion sort, Fibonacci, fatorial (iterativo e recursivo), FizzBuzz, Crivo de Eratóstenes
Funções e recursão
Criptografia: cifra de César (criptografar/descriptografar)
Validações: validação de CPF
Estatística: média, desvio padrão
Visualização de dados: gráfico de barras com matplotlib
Mini-projetos/jogos: jogo de adivinhação, jogo da forca, jogo da velha, jogo de dados, gerador de senhas, lista de compras (CRUD simples), calculadora
